# AsyncAwaitLearn

Este repositorio alberga un ejemplo sencillo de consola que imprime un saludo.
El objetivo es sentar las bases para introducir ejemplos de Async/Await en el futuro.


## Requisitos

- .NET 8 SDK.

## Ejecución

```bash
dotnet run --project AsyncAwaitLearn
```

## Pruebas

```bash
dotnet test
```
